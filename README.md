# Projects

Personal collection of projects.

## How this repository is organized

- `main` contains only this README, as an index of all projects.
- Each project lives on its own branch, created from `main`, with its own README and history.
- The backlog for all projects is tracked through GitHub Issues, labeled by project.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/), with the project name as the scope when relevant, for example `feat(web-scraper): add pagination support`.
